# Wholly fabricated example

`create_example.py` constructs every source value from literals/arithmetic. It never reads
production data. `source.parquet`, `export.json` and `profile.json` are safe demonstration
artifacts generated by that script, not derivatives of `randomized_data.parquet`.

From a checkout:

```console
uv sync --locked
uv run python examples/create_example.py
uv run synthparq generate examples/profile.json --out demo-synthetic.parquet --seed 42
```

The example has 48 rows: 4 fictional entities × 2 series × 6 months. It exercises Decimal,
a composite key, a 1:1 name mapping and regular monthly time series.
The generation script intentionally overwrites the three fabricated example artifacts
when rerun; the normal CLI does not overwrite outputs by default.
